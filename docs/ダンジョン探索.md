# ダンジョン探索

やみまほのダンジョン画面（`/dungeon`）の仕様です。待機画面からダンジョンに入り、「進む」で深さを進めながら戦闘または探索イベントが発生します。

---

## 1. 概要

1. 待機画面で「ダンジョンへ」→ `POST /api/dungeon/enter`
2. ダンジョン画面で「進む」→ `POST /api/dungeon/advance`
3. 応答に応じて戦闘画面へ遷移するか、探索イベント（セリフ・選択）を再生する
4. 探索イベント完了後、再び「進む」可能

---

## 2. 深さ（step）

- `user_dungeon_progress.step` が深さ（0 から開始、進むたびに +1）
- 旧仕様の深さ 1〜6 ループ・`game.dungeon_steps` は廃止（実質無限進行）
- **リセット条件**
  - ダンジョン由来の戦闘で **敗北** したとき（`BattleOrchestrator`）
  - 管理画面で「ダンジョン探索リセット」をオンにして適用したとき
- 通常の戦闘 **勝利** では深さは維持（旧ボス撃破時の step リセットは廃止）

---

## 3. 1 回の「進む」での抽選

定数は [`backend/config/game.php`](../backend/config/game.php) の `dungeon` 配列（CSV にはしない）。

| 定数 | 既定値 | 意味 |
|------|--------|------|
| `battle_encounter_rate` | 20 | 戦闘になる確率（%） |
| `exploration_event_rate` | 80 | 探索イベント（参考値、戦闘と合計 100 想定） |

- `skip_battle_encounters` が ON のユーザーは **常に探索イベント**
- それ以外は `random_int(1, 100)` で戦闘か探索かを決定
- 探索イベントの種類は `dungeon_event_masters` の weight で抽選

---

## 4. 戦闘エンカウント

- マスタ: `dungeon_encounter_masters`（CSV: [`dungeon_encounters.csv`](../backend/database/csv/dungeon_encounters.csv)）
- 列: `code`, `weight`, `boss`, `enemies_json`
- 初期データ: カッパ 2 体（`kappa_group_2`）
- 戦闘メタ: `source=dungeon`, `step`, `boss`

---

## 5. 探索イベント

### セッション

- テーブル: `dungeon_exploration_sessions`
- 進行中は `advance` を **409** で拒否
- 完了時にセッション削除・パーティ HP を API で返却

### segment の種類

| kind | クライアント動作 |
|------|------------------|
| `story` | `StorySequencePlayer` で `lines` をタップ送り → `POST /dungeon/exploration/continue` |
| `choice` | 生存メンバー選択（`lines` があれば先にストーリー再生）→ `POST /dungeon/exploration/choose` |
| `complete` | 終了。パーティ再表示、「進む」復帰 |

イベント終了直前に、エンジンが固定の締め描写 **「一行は先に進むことにした」**（地の文）を必ず 1 行挿入します（CSV 不要）。

### API

| メソッド | パス | ボディ |
|----------|------|--------|
| GET | `/api/dungeon` | —（`step` のみ） |
| POST | `/api/dungeon/enter` | — |
| POST | `/api/dungeon/advance` | — |
| POST | `/api/dungeon/exploration/continue` | `{ "session_id": "uuid" }` |
| POST | `/api/dungeon/exploration/choose` | `{ "session_id", "slot_id" }` |

### 実装クラス（バックエンド）

- `DungeonEventCatalog` … イベント・ノード取得
- `DungeonExplorationEngine` … ノード実行・判定・ダメージ
- `DungeonExplorationService` … start / continue / choose
- `PartyExplorationDamageService` … スロット指定ダメージ

## 6. CSV リファレンス

### dungeon_events.csv

| 列 | 説明 |
|----|------|
| code | イベント ID |
| name | 表示名 |
| weight | 抽選 weight |
| event_type | 拡張用タイプ名 |
| start_node_key | 開始ノード |

### dungeon_event_nodes.csv

| 列 | 説明 |
|----|------|
| event_code / node_key | 複合キー |
| node_type | 下表 |
| text | テンプレート（`{target_name}` `{chosen_name}` `{success_rate}`、改行は `\n`） |
| speaker_role | `target` / `chosen` / `random_ally` / `random_ally_except_target` / `fixed:pc1` など |
| dialogue_pc1〜pc4 | スロット別セリフ |
| stat_attr / stat_multiplier | `stat_check` 用（成功率 = min(100, 能力値 × 倍率)） |
| fixed_damage | `apply_damage` 用 |
| sfx | `attack` など（フロントで SE 再生） |
| next_on_success / next_on_fail / next_default | 遷移先ノード key |

#### node_type 一覧

| type | 動作 |
|------|------|
| narration | 地の文 1 行 |
| dialogue | セリフ 1 行（話者は speaker_role + dialogue_pc*） |
| stat_check | 判定（表示後、continue でロール） |
| party_choice | 生存者選択 UI |
| apply_damage | 固定ダメージ |
| end | セッション終了 |

### dungeon_encounters.csv

`enemies_json` に `[{"slot","master_code","name"}, ...]` を JSON で記載。

## 7. イベントグラフ

### 矢のトラップ（trap_arrow）

```mermaid
flowchart TD
  intro --> intro_react --> dodge_preview --> roll
  roll -->|成功| success_narr --> success_dialogue --> end
  roll -->|失敗| fail_damage --> fail_narr --> fail_ally --> fail_target --> end
```

### 宝箱（treasure_chest）

```mermaid
flowchart TD
  found --> found_rust --> ally_comment --> choose
  choose --> force_open --> str_roll
  str_roll -->|成功| open_success --> herb --> end
  str_roll -->|失敗| open_fail --> fail_dialogue --> end
```

---

## 8. テキスト・判定・SE

- 置換: `{target_name}`, `{chosen_name}`, `{name}`, `{success_rate}`
- 判定: `random_int(1, 100) <= min(100, 能力値 × stat_multiplier)`
- SE: 行オブジェクトの `sfx: "attack"` → BGM 有効時に攻撃 SE（`useBattleAudio`）

---

## 9. 管理画面（/admin）

`POST /api/admins/dungeon-settings`

```json
{
  "skip_battles": true,
  "reset_progress": false
}
```

| フラグ | 動作 |
|--------|------|
| skip_battles | デモユーザーの `skip_battle_encounters` を永続更新 |
| reset_progress | **このリクエスト時のみ** `step = 0` にリセット |

---

## 10. 拡張手順

1. `dungeon_events.csv` に行追加、`dungeon_event_nodes.csv` にノード列を追加
2. `php artisan db:seed --class=MasterDataSeeder`（またはデプロイ時 seed）
3. 新 `event_type` が必要なら `DungeonExplorationEngine` に分岐を追加
4. 固定深度トリガー（旧 step3 匂いストーリー等）は将来 `dungeon_depth_triggers` などで対応可能
