# キャラクターステータス

やみまほのキャラクター・敵キャラクターが持つ能力値の仕様書です。レベルアップで変動する値の設計と、ダメージの算出方法を定義します。

戦闘の操作フローは [`戦闘の流れ.md`](戦闘の流れ.md) を参照してください。

---

## 7つのステータス

味方・敵の双方が、次の7ステータスを持ちます。

| ステータス | 略称（DB） | 戦闘での役割 |
|------------|------------|--------------|
| **筋力** | `str` | こぶしの威力（攻撃力）になる |
| **魔力** | `mag` | 魔法攻撃の威力（攻撃力）になる |
| **防御力** | `def` | 敵から受けるダメージを軽減する |
| **素早さ** | `spd` | 行動順の決定に使用 |
| **知力** | `know` | 戦闘には影響しない。ダンジョン内ギミック用 |
| **精神力** | `spirit` | 戦闘には影響しない。ダンジョン内ギミック用 |
| **体力** | `vit` | 戦闘には影響しない。ダンジョン内ギミック用 |

HP・MP もキャラクターごとに持ちます。HP が 0 になると戦闘不能、MP は魔法の消費に使います。

## ダメージの算出

### 基本式

```
ダメージ = floor( max(1, (攻撃力 - 防御力 ÷ 2) × 乱数 × 魔法係数) )
```

| 要素 | 内容 |
|------|------|
| **攻撃力** | こぶし・キック → **筋力**、魔法 → **魔力** |
| **防御力** | 味方 → **def**、敵の物理 → **pdef**、敵の魔法 → **mdef** |
| **乱数** | **0.9 〜 1.1** の一様乱数（毎回のダメージに揺らぎ） |
| **魔法係数** | わざごとに定義。大技ほど大きい。こぶしは **1.0**（Lv10以降 **1.5**） |
| **最低ダメージ** | 計算結果が 1 未満でも **1** ダメージ |

### こぶし

- 攻撃力 = 攻撃側の **筋力**
- 魔法係数 = **1.0**
- **味方 Lv10 以降** … 係数 **1.5**（全キャラ共通）

### 魔法

- 攻撃力 = 詠唱者の **魔力**
- 魔法係数 = そのわざに設定された係数（回復・バフなどダメージを与えない効果には適用しない）

### キック

- 攻撃力 = 攻撃側の **筋力**
- 魔法係数 = **2.0**
- 命中率 = **50%** 固定（回避率とは別判定）
- **味方 Lv10 以降** … 係数 **3.0**（全キャラ共通）

### クリティカル

- 発生時、被ダメージ側の **防御力を0** としてダメージを再計算する
- 味方デフォルト **5%**、敵はマスター値（デフォルト **1%**）

### バフ・デバフ

- ステータスに倍率を掛ける（防御↑↓、攻撃↑↓、回避50%固定など）

## 素早さ・回避

- **行動順** … 素早さが高いほど先に行動しやすい（ターン順決定に使用）
- **回避率** … 味方デフォルト **5%**、敵はマスター `evasion_rate`（デフォルト **1%**）
- **敵が味方を攻撃するとき** … 物理攻撃（通常攻撃・物理単体技・全体技）にも、ダメージ魔法（即死魔法ソウルハントを含む）にも、**味方の回避率（素の5%）で回避判定**が入る。全体技・全体魔法は対象ごとに別々に判定する。防御ダウンなどのデバフ・回復・バフは回避できない
- **味方が敵を攻撃するとき** … 素の回避率（敵1%）で判定するのは**通常のこぶし**だけ（キック・魔法には効かない）
- **回避バフ**（水の幻影 60%／水の幻影群 30%）がかかっている間は、回避率がその値に**固定**される（素の5%より優先。重なったときは高いほう）。敵からの攻撃だけでなく、味方が敵に出すキック・ダメージ魔法にも、バフがかかっている相手には回避判定が入る
- 回避に成功すると「ミス！」と表示され、ダメージもシールド（魔法障壁）の消費もない

## 武器・防具

味方キャラのみ装備できます。`user_characters` に保存される **6ステータスは素ステ**（レベル成長のみ）で、武器・防具のボーナスは **参照時に加算** します。

| 種別 | 効果 |
|------|------|
| **武器** | 装備時、**魔力** に `mag_bonus` を加算（筋力には影響しない） |
| **防具** | 装備時、**防御力** に `def_bonus` を加算 |

### 装備ティア（`weapon_masters.csv` / `armor_masters.csv`）

| ティア | code 例 | mag_bonus | def_bonus | 価格 | 想定タイミング |
|--------|---------|-----------|-----------|------|----------------|
| 初期 | staff_basic / robe_basic | +1 | +2 | 0 | 開始 |
| 中級 | rod_fire 等 | +3〜+4 | +3〜+5 | ショップ | 1F 中盤 |
| 上級 | staff_advanced / robe_advanced | +8 | +12 | 200 | 1F 後半〜2F |
| 最上級 | staff_master / robe_master | +15 | +18 | 3000 | 2F 後半〜クリア後 |

戦闘・API・ステータス表示の `mag` / `def` は **実効値**（素ステ + 装備）です。敵キャラは武器・防具を持ちません。

### 購入時の自動装備

武具屋（`EquipmentShopService::buy`）で買った武器・防具は、**今の装備より強ければ自動で装備**されます（武器は `mag_bonus`、防具は `def_bonus` で比べ、装備なしの場合も装備）。ボーナスが同じか低いものを買ったときは、所持品に加わるだけで装備は変わりません。買ったキャラ本人の装備だけが対象です。レスポンスの `equipped`（true/false）と `message`（「〜を購入し、装備した。」）で結果を返し、武具屋の画面は装備中のものを「装備中」と表示します。

### CSV

| ファイル | 列 |
|----------|-----|
| `weapon_masters.csv` | `code`, `name`, `mag_bonus`, `description`（任意） |
| `armor_masters.csv` | `code`, `name`, `def_bonus`, `description`（任意） |
| `character_masters.csv` | `default_weapon`, `default_armor` … パーティ初回作成時に自動装備 |

### テーブル

| テーブル | 内容 |
|----------|------|
| `weapon_masters` | 武器マスター |
| `armor_masters` | 防具マスター |
| `user_characters.weapon_master_id` / `armor_master_id` | ユーザーごとの装備 |

## データの管理方針

### 3層構造

```
CSV（初期値）  →  マスターテーブル  →  ユーザー所持キャラ
```

| 層 | 役割 | 更新タイミング |
|----|------|----------------|
| **CSV** | Lv1 時点の **初期ステータス** を定義。バランス調整の正本 | 開発者がファイルを編集 |
| **マスターテーブル** | CSV から取り込んだ **キャラ・敵のテンプレート** | CSV 投入時（Seeder 等） |
| **ユーザー所持キャラ** | プレイヤーごとの **現在のレベル・ステータス** | レベルアップ・成長時 |

### CSV の場所

```
backend/database/csv/
├── character_masters.csv   … 味方キャラ（PC1〜PC4 など）
├── weapon_masters.csv      … 武器（魔力ボーナス）
├── armor_masters.csv       … 防具（防御力ボーナス）
├── enemy_masters.csv       … 敵キャラ（カッパ など）
├── spell_masters.csv       … 魔法の定義（名称・MP・効果・係数など）
├── character_spells.csv    … キャラごとの習得魔法一覧
└── level_masters.csv       … レベルごとの必要 EXP・成長率
```

### マスターテーブル

| テーブル | 内容 |
|----------|------|
| `character_masters` | 味方キャラのマスター定義 |
| `weapon_masters` | 武器マスター |
| `armor_masters` | 防具マスター |
| `enemy_masters` | 敵キャラのマスター定義 |
| `spell_masters` | 魔法のマスター定義 |
| `character_spell_masters` | キャラと魔法の紐付け（並び順 `sort_order`、覚える条件 `learn_after_defeat`、忘れる条件 `replaced_by`） |
| `level_masters` | レベルごとの必要 EXP・成長率 |

### ユーザーごとのデータ

| テーブル | 内容 |
|----------|------|
| `user_characters` | ユーザーが所持するキャラの **現在** のレベル・HP/MP・6ステータス（素ステ）・装備 FK |
| `user_character_learned_spells` | キャラが敵を倒して覚えた魔法（`spell_code`）。キャラの作り直し（リセット）で一緒に消える |
| `user_characters.max_mp_bonus` | レベル成長とは別に加算された最大MP（イフリーヌ初回撃破のサフィリア +10 など）。最大MPは `LevelGrowthService::statsForCharacter`（= `statsForLevel` の MP + この値）で求める |

レベルアップや装備などでステータスが変わったあとは、**必ず `user_characters` を参照**します。CSV やマスターは初期値の定義のみです。

### 成長（実装済み）

- **勝利時** … 生存パーティ全員が、撃破した敵の `exp_reward` 合計を同額獲得
- **レベルアップ** … 累計 EXP が [`level_masters.csv`](../backend/database/csv/level_masters.csv) の閾値に達すると Lv+1（EXP は減らさない）
- **必要 EXP（累計）** … Lv2=50、Lv3=105 … **Lv8=484**、**Lv12=962**（1層クリア Lv8 目標）。CSV の `exp_to_next` は「そのレベルから次へ上がるまでの累計」なので、Lv13 行の値 = Lv14 到達に必要な累計 EXP。**Lv12 までは従来どおり。Lv13 以降は上がりにくくしてある**（以前は Lv20 で 7,800 だったのを、Lv18 で 7,800 にした。つまり同じ経験値で 2 レベル低い）。**Lv13〜18 は手動で調整した値**（累計 1,200 / 1,800 / 2,750 / 4,050 / 5,750 / 7,800。増分は 238 → 600 → 950 → 1,300 → 1,700 → 2,050）。**Lv19 以降は、以前の表を 2 レベルぶん後ろへずらしたもの**（増分が 1 レベルごとに +250 ずつ伸びる。Lv19=9,850〈増分 2,050〉、Lv20=12,150、Lv25=27,400、Lv30=48,900、Lv40=110,650、Lv50=197,400〈増分 9,800〉）。途中の行を直したら、以降の行も同じ要領で作り直すこと（前の行より小さくなると逆転する。`LevelGrowthServiceTest::test_exp_curve_gets_steeper_from_level_12` が単調性を確かめる）
- **ステ上昇**（レベルアップ 1 回ごと、`LevelGrowthService` で固定。`level_masters.csv` の成長率列は未使用）
  - **HP** … 前レベル + **10**（固定加算）
  - **MP** … 前レベル + **3**（固定加算）
  - **魔力・防御力** … 前レベル + **2**（固定加算）
  - **筋力・素早さ・知力・精神力・体力** … 前レベル + **1**（固定加算）
  - **ただし Lv4 に上がるときだけ** … HP **+20**、MP **+6**、魔力・防御力 **+4**、その他 **+3**（`LevelGrowthService` の `GROWTH_BY_REACHED_LEVEL`。他のレベルを特別扱いしたい場合もここに足す）
  - **Lv7 に上がるときだけ** … その他（筋力・素早さ・知力・精神力・体力）**+3**。HP・MP・魔力・防御力は通常どおり
  - **Lv12 以降に上がるときは常に** … HP **+25**、MP **+5**、魔力・防御力 **+4**、その他 **+2**（`LATE_GROWTH`。Lv12 に上がる分から Lv13、14 … も同じ。**ただし Lv18 に上がるときを除く**）
  - **Lv18 に上がるときだけ** … HP **+50**、MP **+10**、魔力・防御力 **+8**、その他 **+4**（`GROWTH_BY_REACHED_LEVEL`。通常の Lv12 以降の上昇値の代わりに使う。Lv19・Lv20 はまた通常の Lv12 以降の値に戻る）
  - **Lv21 以降に上がるときは常に** … HP **+40**、MP **+6**、魔力・防御力 **+6**、その他 **+3**（`VETERAN_GROWTH`。Lv21 に上がる分から Lv50 まで同じ。Lv12〜20 の値の代わりに使う）
- **HP/MP** … 戦闘終了時に残り HP/MP を保存。レベルアップ時は最大値の増加分だけ回復

#### 既存セーブへの影響

成長ルールを変えたときの既存セーブの扱いは、ステータスごとに異なります。

- **最大 HP・最大 MP** … 常にレベルと成長式から算出するため、変更は即座に反映されます（現在値は新しい最大値を超えない範囲で据え置き）。
- **筋力・魔力・防御・素早さ・知力・精神力** … `user_characters` の DB 保存値のため、**次のレベルアップ時**、または**全回復時**（撤退・敗北・ボス撃破でホームへ戻るとき）に新式の値へ置き換わります。値が下がる場合もあります。
- **体力** … パーティ取得時（`ensureParty`）に毎回、新式へ同期されます。

装備ボーナスはマスター参照のため CSV 更新後すぐ反映されます。

## 魔法係数（わざ）

各魔法には **魔法係数** を設定します。代表値:

| 魔法 | 係数 |
|------|------|
| 水の刃 / ツルの鞭 / 石弾 | 2.3 |
| 炎弾 | 2.4 |
| 火炎波及（全体） | 1.7 |
| 爆破 | 3.0 |
| 岩落とし | 3.0 |
| ブラックホール（全体・闇） | 3.0 |
| 水の凶刃 / ツルの大槍（◆2層ボスで習得） | 3.0 |
| 大爆発（◆） | 3.6 |
| 竜の息吹き（全体・◆） | 2.4 |
| 流星群（全体・◆） | 1.7 |

定義は [`backend/database/csv/spell_masters.csv`](../backend/database/csv/spell_masters.csv) に記載します。

| CSV 列 | 内容 |
|--------|------|
| `code` | 魔法 ID（戦闘内で参照） |
| `label` / `description` | 表示名・説明 |
| `mp_cost` / `target_type` / `effect` | MP・対象・効果種別 |
| `element` / `coefficient` | 属性・ダメージ係数（攻撃魔法）。回復魔法（`heal_mag`）では回復倍率（神聖の水=2.5。空なら `heal_mag_multiplier`） |
| `power` | 回復量（`heal`）、蘇生の成功率 %（`revive_chance`。蘇生後のHPは `revive_hp_percent`=50%）、HP 消費の割合 %（`damage_hp_cost`） |
| `buff_key` | バフ/デバフ ID（`battle.php` の `buffs` を参照） |
| `cast_style` | 空 = 通常の魔法（「〇〇は△△を唱えた！」）／ `skill` = 魔法ではない特技（「〇〇の△△！」。迅速調合） |

`effect` の種類: `instant_death`（`power` % で対象を即死。ソウルハント）/ `damage` / `damage_hp_cost`（ダメージ＋自分のHP消費。ブラックホール）/ `heal_mag`（魔力×係数。`ally_all` なら味方全体で、満タン・戦闘不能の味方は対象外。精霊の虹）/ `heal` / `heal_full`（HP全回復。精霊の水）/ `revive_chance` / `revive_full`（確実にHP全回復で蘇生。宇宙樹の雫）/ `life_ward`（命の加護。戦闘不能になる攻撃を受けても HP 1 で残る。1回だけ・永続）/ `buff_def` / `debuff_def` / `debuff_def_both`（対象と自分の両方に防御ダウン。ラグオンビート）/ `buff_evasion_set` / `shield_next`。`target_type` は `enemy_single` / `enemy_all` / `ally_single` / `ally_all`。

`character_spells.csv`（キャラごとの魔法と並び順）は `character_code, spell_code, sort_order, learn_after_defeat, replaced_by`。`learn_after_defeat` に敵コードがある魔法は、その敵を倒したときに覚えます（空 = 最初から使える。`inu_moe` = イフリーヌ、`dragon` = 2層ボスのエルドラゴン）。`replaced_by` に魔法コードがある魔法は、その魔法を覚えたときに忘れます（強化版への置き換え。空 = 忘れない）。置き換える魔法と置き換えられる魔法は `sort_order` を同じ値にしてあります（同時には存在しないため）。[戦闘の流れ.md](戦闘の流れ.md) の「新しい魔法の習得」参照。

CSV 編集後は `php artisan db:seed --class=MasterDataSeeder` で DB に反映してください。
