# iPhone Safari 実機確認手順

パフォーマンス改善（文字送り・SE・素材最適化）後の確認チェックリストです。

## 前提

- iPhone と Mac を同一 Wi‑Fi に接続
- Mac の Safari → **開発** メニュー → 接続中の iPhone → 対象ページを選択（Web Inspector）

## 1. 探索イベント（文字送り・発熱）

1. ホームからダンジョンへ入り、イベントを **10 連続** 進める
2. 確認項目:
   - 文字送り中に画面がカクつかないか
   - **1 回目のタップ**でその行が全文表示されるか（2 回目で次行）
   - 長文でも端末が異常に熱くならないか
3. （任意）Web Inspector → **Timelines** で Main thread の Scripting 占有率を確認

## 2. 戦闘 SE（欠落しないか）

1. BGM を **オフ** にした状態でも SE が鳴るか（cursor / damage / magic 等）
2. 戦闘 1 回で以下を確認:
   - コマンド選択時の `cursor`
   - 攻撃・魔法・被弾 SE が **連続・重なっても欠落しない** か
3. 初回タップ前は iOS 制限で SE が鳴らない場合がある → ホームまたは探索で 1 回タップ後に再確認
4. **音量が効くか**（音は Web Audio API で鳴らしており、iOS でもスライダーが効くはず）
   - 画面右上の ♪ → **効果音** スライダーを動かし、離したときに鳴る試し聴き（`damage`）の大きさが変わるか
   - **BGM音量** スライダーで BGM の大きさが変わるか
   - BGM をオンにした状態で、SE が BGM に埋もれず聞き取れるか（SE の既定は 0.3。小さければスライダーを上げる）
5. サイレントスイッチ（マナーモード）をオンにしても鳴るか（iOS 16.4 以降は `navigator.audioSession` で鳴る想定。それ未満は鳴らない場合あり）
6. Web Inspector のコンソールで `new Audio().volume = 0.1` のあと `.volume` を読むと 1 のままなのは正常（iOS は `audio.volume` を無視する。だからゲインで音量を掛けている）

### 音量の仕組み（調整するとき）

- `frontend/src/composables/useBattleAudio.js` の `GainNode` で掛ける（BGM は `bgmGain`、SE は `seGain`）。
- BGM = スライダー値 × `BGM_MASTER_GAIN`（0.10）。SE = スライダー値 × 音源ごとの補正ゲイン。
- SE の音源は音量がまちまちなので、実測ラウドネス（`SE_SOURCE_LEVELS`）から `SE_TARGET_LUFS`（-20）に揃える補正を自動計算している。`cursor` は音源が小さく、割れない範囲までしか持ち上げられないため、他よりやや小さめになる。
- SE の音源を差し替えたら、`ffmpeg -i <file> -af loudnorm=I=-23:TP=-1:print_format=json -f null -` で `input_i`（LUFS）と `input_tp`（ピーク）を測り直し、`SE_SOURCE_LEVELS` を更新する。

## 3. 素材・転送量

1. Web Inspector → **Network** を開き、ページ再読み込み
2. 確認項目:
   - キャラ立ち絵が `.webp` で取得されているか（非対応時は `.png`）
   - BGM / SE の合計転送量が改善前より減っているか

## 4. アクセシビリティ（任意）

- iOS **設定 → アクセシビリティ → 動作 → アニメーションを減らす** をオン
- 探索テキストが **即全文表示** になるか

## 5. 戦闘エフェクト（モバイル簡略化）

- タッチデバイス（`(pointer: coarse)`）で支援魔法の光エフェクトが **軽量（transform のみ）** になっているか
- 行動中パーティ枠の **unitPulse 無限アニメ** が動いていないか

## 問題が残る場合

| 症状 | 確認ポイント |
|------|-------------|
| SE が鳴らない | 画面タップで `unlock()` 済みか、効果音スライダーが 0 でないか、サイレントスイッチ（iOS 16.4 未満では Web Audio がマナーモードで無音になる）、`heal` は音源ファイル（`heal.mp3`）が未配置で鳴らない |
| 文字が読めない | 1 タップ目 = skip、2 タップ目 = 次行 の挙動 |
| 初回だけ重い | Network で WebP / 圧縮 BGM が配信されているか |
