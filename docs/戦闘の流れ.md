# 戦闘の流れ

やみまほのターン制戦闘の仕様書です。プレイヤーが画面上で体験する流れと、戦闘中に起きることだけを記載しています。

キャラクターの能力値・ダメージ計算の詳細は [`キャラクターステータス.md`](キャラクターステータス.md) を参照してください。

---

## 概要

- **味方**: 4人パーティ（PC1・PC2・PC3・PC4）
- **敵**: 戦闘ごとに1〜3体（デモはコーモリ3体、ボスデモはイフリーヌ1体）
- **形式**: ターン制。順番が回ってきたキャラが行動する
- **勝利条件**: 敵をすべて倒す
- **敗北条件**: 味方がすべて倒れる

---

## ターン順

戦闘開始時に、**素早さが高いキャラから** 1ラウンドの順番が決まります（同じ素早さのときはスロット順）。

- 倒れたキャラは順番から外れます
- 味方の手番のときだけ、プレイヤーが操作できます
- 敵の手番は自動で進みます

---

## 1ラウンドの流れ（味方の手番）

### 1. 手番の確認

画面上部に「○○ のターン」と表示されます。光っている味方が、いま操作できるキャラです。

### 2. コマンドを選ぶ

手番の味方をタップすると、コマンド一覧が開きます。

| コマンド | 説明 |
|----------|------|
| **こぶし** | 物理攻撃。敵1体を選んでダメージを与える |
| **キック** | 物理攻撃。命中率50%だが威力は筋力×2（Lv10以降は×3） |
| **魔法** | キャラごとに3種類。MPを消費して効果を発動する |

### 3. 対象を選ぶ

| 種類 | 操作 |
|------|------|
| こぶし・キック・単体攻撃魔法 | 攻撃する敵をタップ |
| 単体回復・単体バフ魔法 | 対象の味方をタップ |
| 全体攻撃魔法 | 対象を確認して **決定** ボタンを押す |

MPが足りない魔法は選べません。

### 4. 行動の解決

選び終えると演出が再生されます。

1. **行動メッセージ**（例: 「PC1のこぶし！」「PC1は癒しの水を詠唱した！」）
2. **ダメージ・回復エフェクト**（数値はフロート表示。HPバーはこのタイミングで減算）
3. 短い間隔のあと、次のイベントへ

ダメージ数値専用のバナーは表示しません。

### 5. 手番終了 → 敵フェーズ

味方1人の行動が終わると、続けて敵の手番が自動で進みます。

- 各敵はマスターに応じた行動を抽選します（通常攻撃・特技など）
- イフリーヌは「攻撃」「炎のキバ」「火炎放射」を確率で使用します

---

## 敵の手番

- 画面上部に「敵のターン」と表示されます
- プレイヤーは操作できません
- 行動前に「○○の攻撃！」「○○の炎のキバ！」などのメッセージが表示されます
- **演出の順序（フロント `BattleView.vue` の `playEvents`）** … 敵の物理攻撃は「アイコンが前に出る（約0.3秒）→ 告知」。**魔法の詠唱はアイコンを動かさず**、PC の魔法と同じように手番の開始からすぐ「○○は△△を唱えた！」を出す（動いてから遅れて出るとテンポが悪いため）。次のイベントが「唱え」の告知かどうかで判定する
- 敵の行動は [`enemy_skills.csv`](../backend/database/csv/enemy_skills.csv) の `weight`（比率）で抽選します。`action_type` は `punch`（攻撃）/ `physical_single` / `physical_all`（全体）/ `spell` / `flee`（逃げる）
- `spell` の行は `skill_code` が `spell_masters.csv` の魔法コードです。対象・威力・「○○は△△を唱えた！」の魔法名は魔法側の定義で決まり、`target_type` と `coefficient` の列は使いません（空にしておく）。敵は MP を消費しません
- **即死魔法（刈り取る奴のソウルハント = `zaraki`）** … `effect=instant_death`、`power` が成功率（%、現在 10）。成功すると対象の残り HP 分のダメージとして扱い（「即死！」表示・闇属性のフラッシュ）、魔法障壁（次のダメージ無効）で防げます。外れると「効果がなかった…」
- **敵の逃走（ミミック）** … ミミックは手番ごとに 50% で攻撃、50% で逃げます（`mimic,flee` 行）。逃げた敵は戦闘不能と同じ扱い（`alive=false`、`fled=true`）で、画面から消えます。**倒したわけではないので経験値・ゴールドは入りません**。敵が全員いなくなったら通常どおり勝利（結果画面は報酬なし）。逃げた敵は「倒した敵」に数えないため、イフリーヌの魔法習得などの条件にもなりません
- **2層ボスの技・魔法** … 強さの数値は [`enemy_masters.csv`](../backend/database/csv/enemy_masters.csv)、行動の比率は `enemy_skills.csv` の `weight` で決まります

  | 敵 | 行動（抽選の比率） | 内容 |
  |----|--------------------|------|
  | エルドラゴン（`dragon`） | 攻撃 30 | 単体への通常攻撃（係数 1.0） |
  | | ドラゴンクロウ 35 | 単体の大ダメージ（筋力×係数 1.5。イフリーヌの炎のキバ 1.4 より強い） |
  | | ドラゴンブレス 35 | 味方全体にダメージ（係数 0.9。イフリーヌの火炎放射と同じ） |
  | 邪教徒（`mahou`） | 攻撃 25 | 単体への通常攻撃 |
  | | 闇の加護 25（`cult_def_up`） | 3ターン、**敵全員**（倒れていない邪教徒・ドラゴン、自分も含む）の防御力を少し上げる（×1.2） |
  | | 闇の呪縛 25（`cult_def_down`） | 3ターン、**味方（プレイヤー側）全員**の防御力を少し下げる（×0.8） |
  | | 闇の癒し 25（`cult_heal`） | 敵のうち HP の割合がいちばん減っている1体を、魔力×2.5 回復（邪教徒の魔力 150 なら 375。プレイヤーの神聖の水 ×3.5 より控えめ） |

  魔法の名前・効果は `spell_masters.csv` の `cult_*` 行です（敵専用。プレイヤーの魔法メニューには出ません）。敵視点では `ally_*` は敵側、`enemy_*` はプレイヤー側を指します。**傷ついた敵がいないときに闇の癒しを引いた場合は、空振りさせず通常攻撃になります**
- **画面フラッシュ**は魔法詠唱（「○○は△△を唱えた！」表示）時のみ。ダメージ時はフラッシュなし（揺れ・数値のみ）
- **HPバーはダメージエフェクト（揺れ・数値）の後**に減ります。敵ターン開始時点では減らない
- **戦闘不能のグレーアウト**も HP バーと同様、`displayHp` が 0 になったタイミング（ダメージエフェクト後）で表示する

### HP 表示タイミング（実装規約）

- API の `state.units[].hp` は **その手の全イベント（味方＋敵フェーズ）適用後**の確定値
- フロントは `displayHp` で表示用 HP を管理し、イベント再生前にスナップショット／巻き戻ししてから `damage` イベントで減算する
- `displayHp` にキーがある間は `state.units[].hp` を HP バーに直接使わない（敵ターン開始時の一括減少を防ぐ）

### 新しい魔法の習得（イフリーヌ初回撃破）

- **条件** … 勝利した戦闘で `inu_moe`（イフリーヌ）を倒したとき。1層ボス・ホームの「1層ボス戦」・テスト戦闘（`/test_battles`）の1層ボスのどれでも同じ処理です（2層ボスはイフリーヌではなくなったため対象外）。戦闘不能のキャラも含め、**パーティ全員**が覚えます
- **初回のみ** … 覚えた魔法は `user_character_learned_spells` に残るので、2回目以降にイフリーヌを倒しても覚え直しにはなりません
- **データ** … `character_spells.csv` の `learn_after_defeat` に敵コード（`inu_moe`）が入っている魔法が対象。空の魔法は最初から使えます。別の敵で覚える魔法を足すときも、この列に敵コードを入れるだけです
- **使える範囲** … 覚えるまでは戦闘メニューにも、探索中の回復メニュー（神聖の水・宇宙樹の息吹）にも出ません。バランス試行（`battle:simulate`）とデモ戦闘は「最初から使える魔法」だけで動きます
- **API** … 勝利時のイベントに `spells_learned`（`characters: [{slot_id, name, spells: [{id, label}]}]`）が入ります。覚えた人がいない戦闘では出ません
- **結果画面** … 初回のみ、経験値・レベルアップの画面に「次へ」ボタンが出ます。押すと同じ見た目の画面に「サフィリアは新しい魔法を覚えた！」（ガルデ・グレン・シエナ）が並び、従来の帰還ボタン（ダンジョン戦なら「待機画面へ」など）が出ます
- **サフィリアの最大MP +10** … 初回の習得と同じ処理の中で、サフィリア（`pc1`）の最大MPが一度だけ +10 されます（現在のMPも +10）。画面にもメッセージにも出しません。設定は `config/game.php` の `first_defeat_max_mp_bonus`（敵コード => [キャラのマスターコード => 加算MP]）。条件は「その敵で覚える魔法を、そのキャラがまだ一つも覚えていない」ことなので、2 回目以降は増えません
- **リセット** … ホームの「記録をリセット」でキャラが作り直されるので、覚えた魔法も最大MPの加算分もまとめて消え、イフリーヌをもう一度倒せば覚え直し・加算し直しになります

## バフ・デバフ

魔法で付与される効果は、一定の手番数が経つと自然に消えます。キャラ画像の左下に小さなアイコンで表示されます。

| 表示 | 内容 |
|------|------|
| 防御↑ / 防御↑↑ | 防御力上昇 |
| 防御↓ / 防御↓↓ | 防御力低下 |
| 攻撃↑ / 攻撃↑↑ | 筋力（攻撃力）上昇 |
| 攻撃↓ / 攻撃↓↓ | 筋力（攻撃力）低下 |
| 回避 | 回避率を固定（水の幻影=60%、水の幻影群=30%。重なったときは高いほう） |

---

## 回避・クリティカル

- **味方の回避率** … デフォルト5%
- **敵の回避率** … マスター値（デフォルト1%）
- **味方のクリティカル率** … デフォルト5%
- **敵のクリティカル率** … マスター値（デフォルト1%）
- クリティカル時は相手の防御力を0としてダメージを算出します

---

## ダメージの考え方

- **こぶし** … 筋力ベース。回避判定あり。Lv10以降は係数 1.5
- **キック** … 命中率50%固定。命中時は筋力×2（Lv10以降は×3）
- **魔法** … 魔力ベース（回復・バフは別処理）
- HPが0になると、そのキャラは戦闘不能になります

---

## 勝敗

### 勝利

敵すべてのHPが0になったとき、**勝利！** と表示されます。

### 敗北

味方4人すべてが戦闘不能になったとき、**敗北…** と表示されます。

### タイトル画面のデモ

- **戦闘を始める** … コーモリ3体との通常デモ
- **1層ボス戦（イフリーヌ）** … 1層ボスとのデモ戦闘

---

## 画面を再読み込みした場合

戦闘の途中でブラウザを再読み込みしても、HP・手番・MPなどの状態は続きから再開できます。ただし、再読み込み直前の演出は再生されません。
