# 戦闘の流れ

やみまほのターン制戦闘の仕様書です。プレイヤーが画面上で体験する流れと、戦闘中に起きることだけを記載しています。

キャラクターの能力値・ダメージ計算の詳細は [`キャラクターステータス.md`](キャラクターステータス.md) を参照してください。

---

## 概要

- **味方**: 4人パーティ（PC1・PC2・PC3・PC4）
- **敵**: 戦闘ごとに1〜3体（デモはコーモリ3体、ボスデモはイフリーヌ1体）
- **形式**: ターン制。順番が回ってきたキャラが行動する
- **勝利条件**: 敵をすべて倒す
- **敗北条件**: 味方がすべて倒れる

---

## ターン順

戦闘開始時に、**素早さが高いキャラから** 1ラウンドの順番が決まります（同じ素早さのときはスロット順）。

- 倒れたキャラは順番から外れます
- 味方の手番のときだけ、プレイヤーが操作できます
- 敵の手番は自動で進みます

---

## 1ラウンドの流れ（味方の手番）

### 1. 手番の確認

画面上部に「○○ のターン」と表示されます。光っている味方が、いま操作できるキャラです。

### 2. コマンドを選ぶ

手番の味方をタップすると、コマンド一覧が開きます。

| コマンド | 説明 |
|----------|------|
| **こぶし** | 物理攻撃。敵1体を選んでダメージを与える |
| **キック** | 物理攻撃。命中率50%だが威力は筋力×2（Lv10以降は×3） |
| **魔法** | キャラごとに3種類。MPを消費して効果を発動する |

### 3. 対象を選ぶ

| 種類 | 操作 |
|------|------|
| こぶし・キック・単体攻撃魔法 | 攻撃する敵をタップ |
| 単体回復・単体バフ魔法 | 対象の味方をタップ |
| 全体攻撃魔法 | 対象を確認して **決定** ボタンを押す |

MPが足りない魔法は選べません。

### 4. 行動の解決

選び終えると演出が再生されます。

1. **行動メッセージ**（例: 「PC1のこぶし！」「PC1は癒しの水を詠唱した！」）
2. **ダメージ・回復エフェクト**（数値はフロート表示。HPバーはこのタイミングで減算）
3. 短い間隔のあと、次のイベントへ

ダメージ数値専用のバナーは表示しません。

### 5. 手番終了 → 敵フェーズ

味方1人の行動が終わると、続けて敵の手番が自動で進みます。

- 各敵はマスターに応じた行動を抽選します（通常攻撃・特技など）
- イフリーヌは「攻撃」「炎のキバ」「火炎放射」を確率で使用します
- **全員（味方と敵）の行動が一周したとき**、使い魔（Lv1 以上）がいれば支援の抽選が走ります（Lv1〜2 = 20%、Lv3〜6 = 30%、Lv7〜 = 40%）。当たると「使い魔たちの支援行動！」のあと、敵への攻撃・味方の回復・攻撃バフ・蘇生のどれかが発動します。詳細は [使い魔.md](使い魔.md)

## 敵の手番

- 画面上部に「敵のターン」と表示されます
- プレイヤーは操作できません
- 行動前に「○○の攻撃！」「○○の炎のキバ！」などのメッセージが表示されます
- **敵画像の大きさ（フロント `EnemyRow.vue`）** … 画像は枠の幅いっぱいの正方形（縦横比は保つ）。幅の上限は敵の数と、ボス戦かどうかで変わる（`--enemy-slot-max`）。**通常戦は小さめ**（1 体 160px・2 体 125px・3 体以上 95px）、**ボス戦（階層ボス・中ボス＝`meta.boss` / `meta.mid_boss`）は迫力を出すため大きいまま**（1 体 260px・2 体 200px・3 体以上 140px）。数字は `EnemyRow.vue` の `SLOT_MAX_WIDTH`。高さの上限は敵エリア（`.field-top`、`container-type: size`）の高さから名前・HP バー分（56px）を引いた値（`100cqh`）で、画面が低い端末では自動で縮む。NPC（グース／カース）の画像は 600×1200 だが絵は上の約 40% だけ（下は透明）なので、`portrait` クラスで上 600×490 だけを切り出して表示する。ゼロ（`3_zero.png`、1280×600）は横長で、枠の幅に合わせると絵が小さくなるので、`wide` クラス（`WIDE_SPRITE_ASPECT`）で枠の 2.6 倍の幅（最大 420px）に広げ、枠の中央に合わせてはみ出して描く
- **ダメージの数字（フロント `EffectLayer.vue` の `.float-damage`）** … 出てから約 1.25 秒（`BattleView.vue` の `FLOATING_DAMAGE_MS`。以前は 0.9 秒）。出てすぐ薄くなり始めると見づらいので、約 7 割の間は濃いまま保ってから上へ流れて消える（`battle.css` の `floatDamageHold`）。**味方が受けたダメージ**（`.is-ally`）は、大きめ（2.1rem）・太字・赤い字に濃い縁取りで強調する（明るい立ち絵や暗い枠の上でも読めるように。端の味方でも画面からはみ出さないよう、左右 17%〜83% の間に寄せる）。敵が受けたダメージは従来の白い字
- **演出の順序（フロント `BattleView.vue` の `playEvents`）** … 敵は手番の開始で、どの敵の行動か分かるようにアイコンが前に出る（約0.28秒、`ENEMY_LUNGE_MS`）。物理攻撃は「動き終えてから告知」。**魔法の詠唱は動きを待たず**、PC の魔法と同じように手番の開始からすぐ（約0.17秒後）「○○は△△を唱えた！」を出す（動きと告知を同時に進める。動いてから遅れて出るとテンポが悪いため）。次のイベントが「唱え」の告知かどうかで判定する
- 敵の行動は [`enemy_skills.csv`](../backend/database/csv/enemy_skills.csv) の `weight`（比率）で抽選します。`action_type` は `punch`（攻撃）/ `physical_single` / `physical_all`（全体）/ `physical_double`（2 回行動する単体攻撃。下の「3 層の敵の技」）/ `spell` / `flee`（逃げる）
- `spell` の行は `skill_code` が `spell_masters.csv` の魔法コードです。対象・威力・「○○は△△を唱えた！」の魔法名は魔法側の定義で決まり、`target_type` と `coefficient` の列は使いません（空にしておく）。敵は MP を消費しません
- **即死魔法（刈り取る奴のソウルハント = `zaraki`）** … `effect=instant_death`、`power` が成功率（%、現在 10）。成功すると対象の残り HP 分のダメージとして扱い（「即死！」表示・闇属性のフラッシュ）、魔法障壁（次のダメージ無効）で防げます。外れると「効果がなかった…」
- **敵の逃走（ミミック）** … ミミックは手番ごとに 50% で攻撃、50% で逃げます（`mimic,flee` 行）。逃げた敵は戦闘不能と同じ扱い（`alive=false`、`fled=true`）で、画面から消えます。**倒したわけではないので経験値・ゴールドは入りません**。敵が全員いなくなったら通常どおり勝利（結果画面は報酬なし）。逃げた敵は「倒した敵」に数えないため、イフリーヌの魔法習得などの条件にもなりません
- **2層ボスの技・魔法** … 強さの数値は [`enemy_masters.csv`](../backend/database/csv/enemy_masters.csv)、行動の比率は `enemy_skills.csv` の `weight` で決まります

### 空間の裂け目の 4 人の魔法使い

探索イベント「謎の気配」の先の隠しボス。**レベル 35・フル装備（大魔導の杖＆ローブ）・使い魔 Lv9 で、自動シミュレーション（MP を意識して全体魔法・防御ダウン・鋼の城壁・回復・蘇生を使う AI）の勝率が約 70%**（やや優しい）になる強さ。参考: Lv30 では勝率約 6%、Lv40 では約 90%、使い魔なしの Lv35 では約 30%。戦闘中にMPを回復する手段は無いので、長引くほど不利。報酬は 4 人の合計で EXP 40,000・ゴールド 30,000。

|---|---|---|---|---|---|
| 慈愛の魔法使い（`rift_mercy`） | 6800 | 320 | 140 | 160 | 平均的 |
| 伝説の魔法使い（`rift_legend`） | 5200 | 400 | 110 | 150 | 魔力特化 |
| 奏楽の魔法使い（`rift_music`） | 3400 | 300 | 50 | 240 | 素早さ特化。HP・防御が低い |

- **素早さは Lv35 のパーティー（最大でガルデの 97）より全員高い**ので、戦闘の最初から毎ラウンド、敵が先に動く（開幕の敵フェーズで 4 人とも行動する）。数字は `enemy_masters.csv`
- 技は PC と同じ名前でも**別のデータ**（`spell_masters.csv` の `rift_` で始まる行。PC の魔法一覧には出ない）。敵の行動は `enemy_skills.csv`（重みの抽選。重み 0 の技はターン表のときだけ使う）と **`enemy_skill_rules.csv`**（ターン表）で決める
- **「ターン」はその敵自身の行動の回数**（全員が毎ラウンド 1 回動くので、ラウンド数と同じ）。ルールは CSV の上の行ほど優先。どれにも当てはまらなければ、重みで抽選する

| 敵 | ターン表（`enemy_skill_rules.csv`） | それ以外（重み） |
|---|---|---|
| 慈愛 | 1 ターン目＝命の加護（味方全体）／ 2 ターン目＝鋼の城壁（味方全体の防御+2 段階）／ 5・8・11…ターン目（5 から 3 ごと）＝鋼の城壁 | 石弾 40・流星群 35（全体）・天撃 25（特大） |
| 伝説 | 5 ターン目＝悪魔級殲滅魔法の詠唱を始める | 大爆発 40（特大）・ラグオンビート 40（敵単体の防御-3 段階。**自分は下がらない**）・ブラックホール 20（全体の大ダメージ。HP 消費なし） |
| 奏楽 | 味方が倒れていたら宇宙樹の雫（HP 半分で確実に蘇生。**戦闘で 1 回だけ。最優先**）／ 1・5・10 ターン目＝怨恨の旋律（特技。敵全体の防御-2 段階）／ 2・7・12 ターン目＝逆襲の旋律（特技。味方全体の攻撃+2 段階） | ツルの鞭 35・ツルの大槍 40（大）・迅速調合 25（特技。味方単体を小回復） |

- **回復の条件（`heal_below` = 70）**: 奏楽・光導の回復（迅速調合・精霊の水・精霊の虹）は、**HP が 70% 未満の味方がいるときだけ**有効。そうでなければ、回復を引いても攻撃などから引き直す（空振りしない）。回復の重みは光導で約 2 割なので、回復ばかりにならない。ルールを持たない既存の敵（グース・カース・ナビなど）の「無効な回復は通常攻撃に差し替え」は変わらない
- **命の加護（慈愛）**は味方全体（敵 4 人全員）に付く。敵にも**加護バッジ**が出る。戦闘不能になる攻撃を受けても HP が 1 残る（1 回だけ）
- **悪魔の幻影群**で回避率 20% に固定されている間は、PC のキック・ダメージ魔法も外れることがある（画面に「miss」と出る）
- **悪魔級殲滅魔法（イーヴィルインフィニティ）**: 伝説の魔法使いが 5 ターン目に「おぞましい魔法を唱えようとしている……。」→ 6 ターン目に「おぞましい魔法を詠唱し始めた！」→ 7 ターン目に「悪魔級殲滅魔法（イーヴィルインフィニティ）を唱え終えた！」と出して、**生きている味方全員**に超特大ダメージ（魔法の係数 2.6）。5・6 ターン目はほかの行動をしない。唱え終えるまでに伝説の魔法使いを倒せば不発（詠唱の途中で倒れたら詠唱は消える。奏楽が蘇生しても、続きからは唱えない）。威力は、満タンのレベル 35・フル装備のパーティー（防御なし）で HP の約 67%（HP が約 3 割残る）、奏楽の怨恨の旋律（防御-2 段階）がかかっていて約 78%、ラグオンビート（-3 段階）が重なって約 82% を失う（HP 2〜3 割残る）。命の加護・防御アップ（鋼の城壁）・魔法障壁は、普通のダメージと同じように効く。詠唱の流れは `config/battle.php` の `charged_skills`、実装は `BattleEngine` の `startEnemyCharge` / `continueEnemyCharge`（敵の `action_type = charged_spell`）
- **行動ルール（`enemy_skill_rules.csv`）**: `enemy_code, rule, skill_code, value`。`rule` は `turns`（`1|5|10`）／ `every`（`5/3` = 5 ターン目から 3 ターンごと）／ `ally_fallen_once`（味方が倒れていたら、戦闘で 1 回だけ）／ `heal_below`（`70` = 回復は HP が 70% 未満の味方がいるときだけ）。ルールの無い敵は、今までどおり重みの抽選だけ。選択は `BattleEngine::chooseEnemySkill`（ユニットの `turns_taken`・`once_used`・`charge` を使う）
- 調整のしかた: 難しさは、敵の HP・魔力（`enemy_masters.csv`）と魔法の係数（`spell_masters.csv` の `rift_` 行）で決まる。**魔力が少し変わるだけで勝率が大きく変わる**（ダメージ = (魔力 − 防御÷2) × 係数。魔力を 4 人とも +10 すると勝率が約 10 ポイント下がる）ので、数字は 5〜10 ずつ動かすのがよい。使い魔 Lv9 の効果は大きい（使い魔なしだと勝率が約 40 ポイント下がる）
- 画像は `frontend/public/assets/enemies/rift_*.webp`（1000×1000 の WebP。顔が影になっている）。敵の画像の URL は `frontend/src/utils/enemySprite.js` の `enemySpriteUrl`
- テスト戦闘のボス戦プリセット `rift_boss`（「空間の裂け目」）で、いつでも戦える

### HP 表示タイミング（実装規約）

- API の `state.units[].hp` は **その手の全イベント（味方＋敵フェーズ）適用後**の確定値
- フロントは `displayHp` で表示用 HP を管理し、イベント再生前にスナップショット／巻き戻ししてから `damage` イベントで減算する
- `displayHp` にキーがある間は `state.units[].hp` を HP バーに直接使わない（敵ターン開始時の一括減少を防ぐ）

### 命の加護

- 掛けた味方に「加護」状態（キャラ画像の左下に **加護** バッジ）がつきます。**ターンが経っても消えず**、発動するまで戦闘中ずっと続きます
- 戦闘不能になる攻撃（HP以上のダメージ。即死魔法ソウルハントも同じ扱い）を受けると、HP が 1 だけ残り、加護は消えます。受けたダメージは「残りHP − 1」に減ります
- 魔法障壁（次の被ダメージを無効化）が先に働きます。魔法障壁で防いだぶんは加護を消費しません
- 戦闘が終われば加護は残りません（戦闘ごとに掛け直し）

### 特技スタイル（魔法ではない特技）

`spell_masters.csv` の `cast_style` 列が `skill` の魔法は、魔法ではなく特技として扱います。発動時の告知が「〇〇は△△を唱えた！」ではなく「**〇〇の△△！**」になり、魔法の詠唱演出（フラッシュ・魔法SE）も出ません。MPは通常どおり消費します。探索中の回復メニューでも、メッセージが「△△を唱えた。」ではなく「△△を使った。」になります（現在は迅速調合だけ）。

### 新しい魔法の習得（イフリーヌ・2層ボスの初回撃破）

- **条件** … 勝利した戦闘で、`character_spells.csv` の `learn_after_defeat` に入っている敵を倒したとき。
  - `inu_moe`（イフリーヌ）… 1層ボス・ホームの「1層ボス戦」・テスト戦闘（`/test_battles`）の1層ボスのどれでも同じ処理です（★の魔法）
  - `dragon`（エルドラゴン）… 2層のボス戦（エルドラゴンと邪教徒2体）に勝ったとき。テスト戦闘の2層ボスも同じです（◆の魔法）。邪教徒だけ・中ボス（カース&グース）では覚えません
  - 戦闘不能のキャラも含め、**パーティ全員**が覚えます
- **初回のみ** … 覚えた魔法は `user_character_learned_spells` に残るので、2回目以降に同じ敵を倒しても覚え直しにはなりません
- **忘れる魔法（強化版への置き換え）** … `character_spells.csv` の `replaced_by` に魔法コードが入っている魔法は、**その魔法を覚えたときに忘れ**、メニューにも探索中の回復メニューにも出なくなります（例: ◆大爆樹を覚えると爆樹を忘れる）。現在これで忘れるのは、爆樹・宇宙樹の気配・土の城壁の 3 つだけです（**水の刃とツルの鞭は 2026-11-10 に外した**。強化版と一緒に使える）。忘れるのは置き換え先を覚えたときだけなので、イフリーヌだけ倒した状態では何も忘れません。リセットすると元に戻ります
- **データ** … `character_spells.csv` の `learn_after_defeat` に敵コード（`inu_moe`）が入っている魔法が対象。空の魔法は最初から使えます。別の敵で覚える魔法を足すときも、この列に敵コードを入れるだけです
- **使える範囲** … 覚えるまでは戦闘メニューにも、探索中の回復メニュー（神聖の水・精霊の水・精霊の虹・宇宙樹の息吹・宇宙樹の雫・迅速調合など）にも出ません。バランス試行（`battle:simulate`）とデモ戦闘は「最初から使える魔法」だけで動きます
- **API** … 勝利時のイベントに `spells_learned`（`characters: [{slot_id, name, spells: [{id, label}], forgotten: [{id, label}]}]`）が入ります。`forgotten` はこのとき忘れた魔法（なければ空配列）。覚えた人がいない戦闘では出ません
- **結果画面** … 初回のみ、経験値・レベルアップの画面に「次へ」ボタンが出ます。押すと同じ見た目の画面に「サフィリアは新しい魔法を覚えた！」（ガルデ・グレン・シエナ）が並び、続けて忘れた魔法が「ガルデは爆樹を忘れた…」の形で1行ずつ並び、従来の帰還ボタン（ダンジョン戦なら「ホーム画面へ」など）が出ます
- **3 層のボスを初めて倒したときも、サフィリアの最大MP が +40**（2026-11-12 から）。3 層のボスは魔法を覚えないので、上のしくみ（魔法の習得と同時）ではなく、**層の初回クリア**で付与する（`DungeonProgressService::onBossVictory` が、`cleared_floor` がその層より小さいときだけ `UserCharacterService::grantFirstClearMaxMpBonus` を呼ぶ。設定は `config/game.php` の `first_clear_max_mp_bonus`＝層 => [キャラのマスターコード => 加算MP]）。画面にもメッセージにも出さない。クリア済みの 3 層のボスをもう一度倒しても増えない。管理画面で 3 層をクリア済みにした場合は付与されない。リセットで消えて、また初回クリアで付与される
- **サフィリアの最大MP の加算（イフリーヌ +10 / エルドラゴン +20）** … 初回の習得と同じ処理の中で、サフィリア（`pc1`）の最大MPが一度だけ加算されます（現在のMPも同じだけ増える）。イフリーヌ（1層ボス）を初めて倒したときに +10、エルドラゴン（2層ボス）を初めて倒したときに +20（合計 +30）。画面にもメッセージにも出しません。設定は `config/game.php` の `first_defeat_max_mp_bonus`（敵コード => [キャラのマスターコード => 加算MP]）。条件は「その敵で覚える魔法を、そのキャラがまだ一つも覚えていない」ことなので、2 回目以降は増えません
- **リセット** … ホームの「記録をリセット」でキャラが作り直されるので、覚えた魔法も最大MPの加算分もまとめて消え、イフリーヌをもう一度倒せば覚え直し・加算し直しになります

## バフ・デバフ

防御・攻撃のバフ／デバフは **「段階」**（2026-11-13 から）で管理します。最大で **3 段階上昇／3 段階低下**。キャラ画像の左下に、段階を **矢印の数** で表したバッジが出ます（例: 「防御↑↑」= 防御 2 段階上昇、「防御↓↓↓」= 防御 3 段階低下、「攻撃↑」= 攻撃 1 段階上昇。段階が 0 のときは出ません）。

| 段階 | 防御（上昇／低下） | 攻撃（上昇／低下） |
|------|------------------|------------------|
| 1 段階 | ×1.2 ／ ×0.8 | ×1.2 ／ ×0.8 |
| 2 段階 | ×1.4 ／ ×0.65 | ×1.4 ／ ×0.65 |
| 3 段階 | ×1.7 ／ ×0.5 | ×1.6 ／ ×0.5 |

- **防御** は防御・物理防御・魔法防御のすべてに、**攻撃** は筋力と魔力の両方に掛かります（回復量には乗りません）。倍率表は `config/battle.php` の `stage.multipliers`
- **重ねがけができ、段階は合算** … 鋼の城壁（防御+2）のあとに土の鎧（防御+1）を使うと、防御は 3 段階上昇
- **持続ターンは、かけた 1 回ごとに独立**（3 ターン。そのキャラ自身の行動のあとに 1 ずつ減ります）。例: 1 ターン目に鋼の城壁、2 ターン目に土の鎧をサフィリアに使うと、サフィリアは 3 段階上昇。4 ターン目に鋼の城壁が先に切れて 1 段階上昇に戻り、5 ターン目に土の鎧も切れて 0 に戻る。残りターンは画面に出さず、内部（ユニットの `stages`。1 回の付与 = 1 要素）で数えています
- **バフとデバフは合算** … 防御+2 のところにジャミング（-1）を受けると +1、そこに大爆樹（-2）を受けると -1（防御 1 段階低下）。デバフが先に切れれば、バフが戻ってきます
- **上限（+3／-3）を超えた分は無駄になります** … かけた時点で、段階の合計が +3／-3 に収まる分だけ効果が付きます（防御+2 のあとに+2 をかけると、あとの効果は +1 だけ）。そのため、先の効果が切れたあとに残るのは付いた分だけです
- クリティカルは、防御側のバフ／デバフ（防御の段階）を無視します（従来どおり）

| 表示 | 内容 |
|------|------|
| 防御↑ / 防御↑↑ / 防御↑↑↑ | 防御力 1〜3 段階上昇 |
| 防御↓ / 防御↓↓ / 防御↓↓↓ | 防御力 1〜3 段階低下 |
| 攻撃↑ / 攻撃↑↑ / 攻撃↑↑↑ | 攻撃力 1〜3 段階上昇。使い魔の攻撃バフ（Lv6〜7 は 1 段階、Lv8 以降は 2 段階）もこの表示 |
| 攻撃↓ / 攻撃↓↓ / 攻撃↓↓↓ | 攻撃力 1〜3 段階低下（今は使う魔法・敵の技はありませんが、`buff_key` に `atk_down_1`〜`3` を書けば使えます） |
| 回避 | 回避率を固定（水の幻影=60%、水の幻影群=30%。重なったときは高いほう）。物理攻撃・ダメージ魔法のどちらも避けられる。**段階制ではなく従来どおり**（3ターンで消える） |
| 加護 | 命の加護。戦闘不能になる攻撃を受けても HP が 1 だけ残る（1回だけ。ターン経過では消えない） |

魔法に付ける効果は、`spell_masters.csv` の `buff_key`（`def_up_1`〜`3`、`def_down_1`〜`3`、`atk_up_1`〜`3`、`atk_down_1`〜`3`、`evasion_set`、`evasion_set_small`。定義は `config/battle.php` の `buffs`）で決めます。デプロイ時に戦闘の途中だった人に残っている古い形式のバフ（`def_up` など）は、無視されます。

------|------|
| 防御↑ / 防御↑↑ | 防御力上昇 |
| 防御↓ / 防御↓↓ | 防御力低下 |
| 攻撃↑ / 攻撃↑↑ | 筋力（攻撃力）上昇 |
| 攻撃↓ / 攻撃↓↓ | 筋力（攻撃力）低下 |
| 回避 | 回避率を固定（水の幻影=60%、水の幻影群=30%。重なったときは高いほう）。物理攻撃・ダメージ魔法のどちらも避けられる |
| 加護 | 命の加護。戦闘不能になる攻撃を受けても HP が 1 だけ残る（1回だけ。ターン経過では消えない） |
| 攻撃↑ | 攻撃力上昇。使い魔の攻撃バフ（筋力・魔力の両方 ×1.2、使い魔 Lv8 以降は ×1.3）もこの表示 |

## 回避・クリティカル

- **味方の回避率** … デフォルト5%
- **敵の回避率** … マスター値（デフォルト1%）
- **敵が味方を攻撃するとき** … 物理攻撃にもダメージ魔法（即死魔法を含む）にも、味方の回避率（素の5%）で回避判定が入ります。成功すると、ダメージの数字と同じ位置（狙われた味方）に白い「miss」が出ます。全体技・全体魔法は対象ごとに判定します。デバフ・回復・バフは回避できません
- **味方が敵を攻撃するとき** … 素の回避率で判定するのは通常の「こぶし」だけです（キック・魔法には効きません）
- **回避バフ（水の幻影など）がかかっている間は**、回避率がバフの値（60%／30%）に固定されます。バフがかかっている相手には、キックやダメージ魔法にも回避判定が入ります
- **外れたときの表示** … 味方の攻撃が敵に外れたときも、敵の攻撃が味方に外れたときも、狙われたユニットの位置に、ダメージの数字と同じ動きで白い「miss」が出ます（外れの SE も鳴ります。画面中央の「攻撃は外れた」のバナーは廃止）。表示は `BattleView.vue` の `showFloatingDamage(…, miss = true)` と `EffectLayer.vue` の `.is-miss`
- **味方のクリティカル率** … デフォルト5%
- **敵のクリティカル率** … マスター値（デフォルト1%）
- クリティカル時は相手の防御力を0としてダメージを算出します

---

## ダメージの考え方

- **こぶし** … 筋力ベース。回避判定あり。Lv10以降は係数 1.5
- **キック** … 命中率50%固定。命中時は筋力×2（Lv10以降は×3）
- **魔法** … 魔力ベース（回復・バフは別処理）
- HPが0になると、そのキャラは戦闘不能になります

## 勝敗

### 勝利

敵すべてのHPが0になったとき、**勝利！** と表示されます。

- **戦闘中に倒れた味方は、戦闘が終わっても倒れたまま**（HP 0）です。即死魔法で倒れた場合も同じです。探索画面の「＋ 回復」で、蘇生の魔法か宇宙樹の葉を使うと戻ります
- 経験値は、戦闘が終わった時点で**生きている味方だけ**に入ります（倒れた味方には入らない）
- 倒れるまでに使った MP も、戦闘後のステータスに反映されます（`BattleRewardService::applyVictoryRewards`）。以前は倒れた味方の HP・MP を保存しておらず、戦闘前の HP に戻って「復活」して見えるバグがあった（2026-11-12 修正）

### 敗北

味方4人すべてが戦闘不能になったとき、**敗北…** と表示されます。

### タイトル画面のデモ

- **戦闘を始める** … コーモリ3体との通常デモ
- **1層ボス戦（イフリーヌ）** … 1層ボスとのデモ戦闘

## 画面を再読み込みした場合

戦闘の途中でブラウザを再読み込みしても、HP・手番・MPなどの状態は続きから再開できます。ただし、再読み込み直前の演出は再生されません。
