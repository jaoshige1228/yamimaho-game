# 戦闘の流れ

やみまほのターン制戦闘の仕様書です。プレイヤーが画面上で体験する流れと、戦闘中に起きることだけを記載しています。

キャラクターの能力値・ダメージ計算の詳細は [`キャラクターステータス.md`](キャラクターステータス.md) を参照してください。

---

## 概要

- **味方**: 4人パーティ（PC1・PC2・PC3・PC4）
- **敵**: 3体（カッパA・カッパB・カッパC）
- **形式**: ターン制。順番が回ってきたキャラが行動する
- **勝利条件**: 敵をすべて倒す
- **敗北条件**: 味方がすべて倒れる

---

## ターン順

戦闘開始時に、**素早さが高いキャラから** 1ラウンドの順番が決まります（同じ素早さのときはスロット順）。

デモの初期パーティだと、おおよそ次のような並びになります。

```
PC3 → PC1 → PC2 → PC4 → カッパA → カッパB → カッパC → PC3 → …
```

- 倒れたキャラは順番から外れます
- 味方の手番のときだけ、プレイヤーが操作できます
- 敵の手番は自動で進みます

---

## 1ラウンドの流れ（味方の手番）

### 1. 手番の確認

画面上部に「○○ のターン」と表示されます。光っている味方が、いま操作できるキャラです。

### 2. コマンドを選ぶ

手番の味方をタップすると、コマンド一覧が開きます。

| コマンド | 説明 |
|----------|------|
| **こぶし** | 物理攻撃。敵1体を選んでダメージを与える |
| **防御** | 防御の構え。次の敵の攻撃まで、受けるダメージが半減する |
| **魔法** | キャラごとに4種類。MPを消費して効果を発動する |

### 3. 対象を選ぶ

選んだコマンドによって、次の操作が変わります。

| 種類 | 操作 |
|------|------|
| こぶし・単体攻撃魔法 | 攻撃する敵をタップ |
| 単体回復・単体バフ魔法 | 対象の味方をタップ |
| 全体攻撃・全体支援魔法 | 対象を確認して **決定** ボタンを押す |
| 防御 | その場で完了（対象選択なし） |

MPが足りない魔法は選べません。

### 4. 行動の解決

選び終えると、ダメージ・回復・バフなどが反映されます。画面には次のような演出が出ます。

- 技名の表示（例: 「PC1のアクアボルト！」）
- ダメージ数値の表示
- HPバーの変化
- 攻撃時の効果音

### 5. 手番終了 → 敵フェーズ

味方1人の行動が終わると、続けて敵の手番が自動で進みます。

- 各敵は **こぶし** でランダムな味方1体を攻撃します
- 敵3体が順に行動したあと、再び味方の手番に戻ります

---

## 敵の手番

- 画面上部に「敵のターン」と表示されます
- プレイヤーは操作できません
- 敵はこぶしのみ使用します
- 味方が防御中なら、受けるダメージは半分になります

---

## 防御のルール

- 防御を選んだキャラは、**次の自分の手番が来るまで** 防御状態が続きます
- 防御中は敵の攻撃によるダメージが **50%** になります
- 自分の次の手番が始まったタイミングで、防御は自動的に解けます
- 防御中でも、こぶしや魔法で攻撃・支援はできます（その場合、防御は解除されます）

## バフ・デバフ

魔法で付与される効果は、一定の手番数が経つと自然に消えます。

| 効果 | 対象ステータス | 持続 |
|------|----------------|------|
| 風のヴェール | 回避（素早さベース） | 3手番 |
| ミストガード | 回避 | 2手番 |
| 岩石の盾 | 防御力 | 3手番 |
| 大地の加護 | 防御力 | 2手番 |
| 縛り根 | 攻撃力（低下） | 3手番 |
| 枯れ葉の呪い | 攻撃力（低下） | 2手番 |

---

## ダメージの考え方

- **こぶし**: 攻撃力と相手の防御力から算出。最低1ダメージ
- **魔法**: 魔法の威力と攻撃力・防御力から算出。最低1ダメージ
- **防御中**: 上記ダメージがさらに半減（最低1ダメージ）
- HPが0になると、そのキャラは戦闘不能になります

---

## 勝敗

### 勝利

敵3体すべてのHPが0になったとき、**勝利！** と表示されます。戦闘BGMはフェードアウトします。

### 敗北

味方4人すべてが戦闘不能になったとき、**敗北…** と表示されます。

### 戦闘後

- **もう一度** … 新しい戦闘を始める
- **タイトルへ** … タイトル画面に戻る

---

## 戦いの記録

画面上部の **記録** ボタンから、直近の戦闘メッセージを確認できます。誰が何をしたかがテキストで残ります。

---

## 画面を再読み込みした場合

戦闘の途中でブラウザを再読み込みしても、HP・手番・MPなどの状態は続きから再開できます。ただし、再読み込み直前の演出（ダメージ数字など）は再生されません。

---

## 音声

- 戦闘中はBGMがループ再生されます
- 画面上部の ♪ ボタンから、BGMのオン・オフと音量を調整できます
- 設定はブラウザに保存され、次回以降も引き継がれます
